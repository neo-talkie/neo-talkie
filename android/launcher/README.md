# NeoTalkie 桌面

Android 应用 ID：`com.neotalkie.launcher`。默认 HOME、应用入口、设备/网络状态、Android 系统设置首页和前台 BLE 手机配网。无语音服务密钥、无模型 SDK。

在仓库根目录运行 `python3 android/scripts/build.py launcher`；输出 `build/neotalkie-launcher.apk`。PTT 跨应用接口见 [架构](../../docs/architecture.md)。BLE 配网与物理授权见 [协议和验收](../../docs/ble-provisioning.md)。

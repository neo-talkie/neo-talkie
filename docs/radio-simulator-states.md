# 手台 UI 回归场景清单

由 `node tools/simulator/scripts/catalog.mjs` 从预设生成。编号与总览 PNG、JSON 参数一致；稳定 ID 用于跨版本对照。

当前基准：Android 0.2.3。共 185 个命名场景；这是应用页面和代表性边界覆盖，不是所有数值组合，也不覆盖厂家 ROM 界面。参数和使用方法见 [模拟器文档](radio-simulator.md)。

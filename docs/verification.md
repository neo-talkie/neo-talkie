# NeoTalkie 验收记录

日期：2026-11-24。当前为独立设备仓库的开发版本，采用 Apache-2.0。

## 本地已验证

- 桌面和对讲两个 APK 分别构建，并通过 APK 签名验证；两包使用同一本地开发签名，包名不同。
- 238 项已有 Java 离线检查，以及 10 项跨应用 PTT 令牌生命周期检查。
- 40 项模拟器测试，1,307 组 Java/JavaScript 行为对照。
- 151 个 UI 场景、226 项浏览器检查，固定场景两次渲染一致；检查了新品牌桌面、桌面设置、网络/系统状态的图册。截图为模拟器画面。
- 公开文件清单检查：不含服务器模块、私有配置、签名、录音、本机绝对路径或旧产品标识；本地构建工具、APK 和 QR 位于忽略目录。该检查是针对迁移清单的静态检查，不替代公开发行前的代码审阅。

## 真机部署与待验证项目

已在 mx_b5 / Android 5.1.1 验证初始安装、对讲就绪、签名保护的系统状态跳转，以及清理旧应用后重启进入 NeoTalkie 桌面。两个 APK 在 0.1.2 时完成覆盖更新；桌面增加第四项「手机配网」，已在真机进入验证页并确认 BLE 广播启动。接收实验组件已移除，桌面不申请麦克风权限，原有对讲配置保留。尚未验证以下项目：

- 实体 PTT 冷/热启动交接、快速松手、重复广播、进程重启和打断播放。
- USB 拔线后的长待机、40 秒息屏与 PTT 唤醒，实际音量和麦克风/扬声器。
- 新固件系统 Wi-Fi 页面在小屏上的可操作性、联网成功和错误密码反馈。
- 使用操作者自己的密钥和模型完成 ASR → AI → TTS；自动测试不调用这些服务。
- Android 手机微信真机上的蓝牙授权、扫描、连接和双向验证结果；iPhone 已通过本轮验证。

连接新设备后，按 [新设备启用](getting-started.md) 执行 doctor → install → home → 私有配置 → 离线 PTT → 明确触发的真实对话，并记录设备/固件及结果。

## 尚未实现的功能

音色/回复设置及语音密钥下发尚未实现。0.2.1 已实现基于确认码与物理按键授权的加密 Wi-Fi 配网；对讲配置仍需 ADB，不能仅靠小程序完成全部新机配置。

2026-11-24 已在 Android 5.1.1 手台验证 BLE 收发及 Wi-Fi 配网成功。0.2.2 的两个 APK 已覆盖安装，系统设置入口已在真机验证。

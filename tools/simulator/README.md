# NeoTalkie 手台界面模拟器

在工作区的 `neo-talkie-design-studio/` 目录运行 `npm start` 打开手台设计工作台。首页按应用展示设计稿和 Android 实图，右上角可进入交互模拟器。固件使用固定发行副本执行离线校验。

在电脑浏览器里回顾弘讯手台各状态的界面、操作按键和导出评审图片。独立于 Android APK；运行无需手台、ADB、密钥或云服务。

默认地址为 <http://127.0.0.1:4176>，只监听本机。

- **手台外观**：仿照参考照片重绘机壳、天线、旋钮、PTT 与上下圆形侧键。实体按键可直接点击。
- **点阵屏幕**：160×128 原始 Canvas，2/3/4/6 倍最近邻放大，可叠加像素网格。
- **状态总览**：177 个回归场景；点击继续编辑，也可整张导出。
- **画面参数**：调整页面、页码、选中项、状态标题、文字、时间、电量、Wi-Fi、音量、录音秒数和声音强度；完整状态 JSON 可编辑设备/网络数据、服务检测结果和桌面应用列表。
- **留档**：保存本机快照；导出/导入 JSON 参数；导出 160×128 PNG、4× PNG、带机壳 PNG、全部状态总览 PNG。图片导出不包含预览用的网格遮罩。

选中预设时画面冻结，适合截图。播放按钮运行本地演示；点击实体按键会启动相关的模拟计时。空格按住为 PTT，松开进入模拟识别→思考→合成→播报→三秒恢复。上下键在正文超出四行时逐行翻看，最后操作后五秒退出翻看；其他情况下调整音量。旋钮左右半区分别减/加音量。

| 快捷键 | 操作 |
| --- | --- |
| 空格 | 按住/松开 PTT；桌面先打开对讲 |
| ↑ / ↓ | 菜单选择、长文翻行或详情翻页 |
| Enter | 状态页确认；主界面无动作 |
| F8 / M | 下侧圆键按配置顺序轮换频道，屏幕显示当前名称 |
| Esc | 返回；运行中停止；待机退出到模拟桌面 |
| + / - | 旋钮音量 |
| P | 息屏/唤醒 |
| H | 快捷回到模拟桌面 |

输入框获得焦点时不触发硬件快捷键。前面板 MENU 打开一级菜单并确认进入；EXIT 逐层返回，PTT 从 NeoTalkie 页面直接回到对话。系统状态、网络数据和连通性检测结果均为**可编辑的模拟数据**，不会真的检测网络服务。

## 精度与校准

基准为 `android/` 两个应用及共享 UI 契约 0.2.2：布局坐标、14/16/20 px 字号、颜色、时间点阵数字、Wi-Fi 弧线、电池及充电闪电、PTT 竖向电平、输入与处理阶段的固定状态提示、底部前快后慢的处理等待进度、圆形侧键、两行音量条和固定 20 px 两行/四行文字及 100 ms 底部文字淡出（图标保留）规则按源码复刻。状态测试对 Android 基准坐标和版本设置了变更检查。

这是 **UI 模拟器，不是 Android 系统模拟器**。机壳为参考照片的示意重绘，不代表精确工业尺寸。屏幕先在 160×128 的画布上栅格化，机壳视图为适应电脑窗口会缩放；检查单个像素请切换“点阵屏幕”或导出原始 PNG。厂家实际字体、Android/浏览器字体栅格化和液晶色偏仍可能不同，不能声称与 ROM 截图逐像素完全一致。

已内置 AOSP Roboto/Droid Sans Fallback，首次运行也不访问字体 CDN。可以在“操作与像素校准”载入合法取得的设备 `.ttf/.otf/.woff/.woff2` 字体，仅应用于当前会话，不上传。字体来源、许可证和转换说明见 [THIRD_PARTY.md](THIRD_PARTY.md)。

## 检查

```sh
npm --prefix tools run simulator:test
```

Node 测试覆盖换行、Unicode、逐行翻看、首尾边界、三秒/五秒计时、PTT 打断与 30 秒上限、音量、一级菜单/PTT 跨页返回、参数校验和静态服务器访问边界。测试只访问临时本机 HTTP 服务，不接触外部服务。

`tests/browser-check.js` 是可在已打开模拟器的浏览器上下文执行的异步检查函数，覆盖真实 Canvas、DOM 按键、五秒恢复及 PNG 导出。可将文件内容粘到开发者工具 Console 并用括号包裹调用：`(文件中的函数)()`。不读取手台、不录音、不播音、不调用模型服务。

架构与维护说明：[docs/radio-simulator.md](../../docs/radio-simulator.md)。

## 全量回归

[全部场景清单](../../docs/radio-simulator-states.md)包括对话、系统提示、文字溢出/翻行/淡出、音量与电平、状态栏、一级菜单和设备/网络分页、服务检测成功/失败/空结果、桌面。所有预设可冻结、修改、保存、导入；“导出全部回归状态 JSON”保存这一版的全部参数。

状态总览可一键导出 1808 px 宽的大图，每张屏幕按 2× 原像素绘制，带编号、名称与稳定 ID。`tests/export-gallery.js` 在页面上下文返回带全部 PNG 的 JSON 包；保存其返回值后，运行 `python3 tools/simulator/scripts/unpack-gallery.py bundle.json output-directory` 生成大图、单张 PNG、单状态参数、完整参数清单和离线 HTML 图册。

新增预设后运行 `node tools/simulator/scripts/catalog.mjs` 同步文档；`--check` 可检查清单是否过期。覆盖检查会对照 Android 的状态标签、功能入口、页面标题和安全错误文案，发现遗漏即失败。系统设置等厂家界面不在模拟范围，桌面的系统应用图标标为占位。

## 两端同步

状态与场景改在 `config/radio-ui/`，执行 `make ui-generate`；`make ui-check` 检查生成漂移、适配复核记录和 Java/JS 行为一致性。`make ui-visual BASE=HEAD` 自动生成本机截图差异；查看后用 `make ui-accept REASON="变更及核对说明"` 更新复核记录。CI 会运行同样的检查并上传图册。完整流程与边界见 [UI 一致性机制](../../docs/radio-ui-contract.md)。
